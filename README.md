# 📈 Digital Marketing Campaign Performance & ROI Analytics (Power BI)

## 🎯 Project Overview
This project was developed during a professional **Data Analytics Course** to demonstrate practical data engineering, semantic modeling, and business intelligence capabilities. Running concurrent advertising campaigns across multiple streams (Google Ads, Instagram, Facebook, YouTube, Email, and SEO) generates massive logs. This interactive system transforms **raw data tracking into centralized, strategic visual insights** to evaluate marketing cost efficiency, minimize ad spend waste, and maximize Return on Investment (ROI).

* **Developer:** Dilshadh J B
* **Core Focus:** Practical Learning Outcome & Portfolio Demonstration

## 🛠️ Tech Stack & Tools Used
* **Power BI Desktop:** Implemented a single-page high-density executive reporting dashboard with dynamic cross-filtering tiers.
* **Power Query Editor:** Built an enterprise-grade extraction pipeline ensuring explicit business schemas, data type enforcement, and zero runtime anomalies across data fields.
* **DAX Formulas:** Formulated advanced, safe arithmetic expressions (utilizing `DIVIDE()`) to eliminate divide-by-zero database calculation bugs.

## 💡 Strategic Business Insights
1. **Top Earning Channels:** Paid search leads macro performance, with **Google Ads driving ₹6.9M in revenue**, closely supported by direct Email Marketing at ₹5.2M. 
2. **Funnel Contribution:** Proportional funnel segmentation proves that **Sales-driven intents capture 44.23% (₹9.2M)** of gross income, showcasing the heavy impact of conversion-oriented design.
3. **Campaign Optimization:** Intent-based, highly personalized initiatives like **Abandoned Cart recovery hit an unmatched ROI of 40x**, compared to top-of-funnel campaigns like Product Carousels which return just 3x.
